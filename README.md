# 轻量记账 (Neo_Book)

## 项目介绍

**轻量记账** 是一款基于纯前端技术（HTML/CSS/JavaScript）构建的轻量级个人财务管理应用。项目设计遵循“极简与实用”的原则，专注于日常收支记录、预算管理以及数据统计可视化。项目原生支持 PWA (Progressive Web App)，可在离线状态下使用，并能安装到桌面或移动设备，提供接近原生应用的使用体验。数据完全存储在本地，注重隐私安全。

## 主要功能

- **基础记账**：支持快速记录支出与收入，支持自定义分类、备注及日期。
- **预算管理**：可设置每月总预算，实时查看预算使用进度和日均预算状况。
- **账单管理**：提供按账本周期、历史全部或自定义日期的账单筛选与搜索功能。
- **数据统计与可视化**：
  - 自动计算日均支出、最大支出项。
  - 提供基于 Canvas 的柱状图与饼图，直观展示分类消费占比。
- **个性化设置**：
  - 支持浅色/深色模式切换。
  - 支持全局背景颜色、卡片颜色、字体颜色自定义，支持设置背景图片。
  - 支持自定义账本周期（自然月或自定义时间段）。
- **数据安全与便携**：
  - 数据完全存储于浏览器 `localStorage`。
  - 支持导出为 JSON 文件进行备份，支持导入已有 JSON 数据。
- **PWA 离线支持**：通过 Service Worker 实现静态资源缓存，支持无网络环境下访问。

## 启动测试方式

项目为纯静态文件，可以通过任何本地 HTTP 服务器启动。

### 方式一：使用内置脚本（推荐，适用于 Windows）

双击项目根目录下的 `start-test-server.bat` 文件，它会自动通过 Python 启动本地测试服务器。
- 访问地址：[http://127.0.0.1:5173/index.html](http://127.0.0.1:5173/index.html)
- 停止方式：在弹出的命令行窗口中按 `Ctrl+C`。

### 方式二：手动启动（需要安装 Python）

在项目根目录下打开终端，执行以下命令：

```bash
python -m http.server 5173 --bind 127.0.0.1
```
然后在浏览器中访问：`http://127.0.0.1:5173/index.html`。

### 方式三：使用 Node.js 工具

如果您习惯使用 Node.js，也可以使用 `http-server` 或 `serve`：
```bash
npx http-server -p 5173
# 或
npx serve -p 5173
```

## 部署方式

由于本项目是纯前端的静态站点，不需要后端的数据库和运行环境，部署非常简单。

### 1. 静态托管平台 (推荐)
可以将代码推送到 GitHub，然后通过以下平台一键免费部署：
- **GitHub Pages**: 在仓库 Settings -> Pages 中开启，选择根目录即可。
- **Vercel / Netlify**: 导入 GitHub 仓库，框架预设选择 `Other` 或保持默认，直接部署。

### 2. 传统 Web 服务器 (Nginx / Apache)
如果拥有自己的云服务器，可将项目文件放置在服务器的 Web 目录下。
**Nginx 配置示例：**
```nginx
server {
    listen 80;
    server_name yourdomain.com;
    root /path/to/Neo_Book;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 使用说明

1. **首页预览**：打开应用后，首页会显示本月支出、结余及预算进度条。点击右上角 ◐ 按钮可切换深色模式。
2. **快速记账**：点击页面右下角的 `+` 悬浮按钮，填写金额、选择分类并保存。
3. **查看统计**：点击底部导航栏的“统计”进入数据分析页面，可切换查看支出和收入的可视化图表。
4. **个性化配置**：在“我的”页面，可以设置预算、管理收支分类、调整外观配色、更改账本周期等。
5. **数据备份**：在“我的”页面点击“导出数据”可下载包含所有记录的 JSON 文件。换设备时可通过“导入数据”恢复账本。

## 开发规范

为了保证项目的可维护性和可扩展性，本项目遵循以下开发规范：
- **纯原生开发**：不依赖 Vue/React 等重型框架，依靠原生 DOM API ( `app.js` ) 与原生 CSS 变量进行状态和主题管理。
- **模块化样式**：CSS 文件 (`styles.css`) 中使用 CSS Variables (`:root`) 集中管理颜色和主题，便于实现多主题切换。
- **语义化标签**：HTML (`index.html`) 采用语义化标签 (`<section>`, `<article>`, `<dialog>`)，提升可读性与无障碍访问 (a11y) 支持。
- **离线优先**：通过 `sw.js` (Service Worker) 与 `manifest.json` 支持离线访问，更新资源时请注意修改 `sw.js` 中的 `CACHE_NAME` 版本号。
- **代码注释**：后续开发中，关键逻辑和复杂的 DOM 操作需配有详细的中文注释，说明代码作用及设计意图。
